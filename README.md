# Pro Mobile League

[Abrir la web](https://promobileleague.pages.dev/) · [Descargar la app Android](https://github.com/Mxxti18/pro-mobile-league/releases/latest/download/Pro-Mobile-League.apk) · [Versiones publicadas](https://github.com/Mxxti18/pro-mobile-league/releases)

La versión 2.0.8 corrige la recuperación de permisos y sincronización, los borradores sin cambios, reservas vencidas de apuestas y la paginación de noticias. Android 7 o posterior. Instalá la actualización sobre PML Torneos, sin desinstalar.

- [Servidor actual y pruebas](games-server/README.md).
- [Cambios de cliente y verificación](updates/2.0.8/README.md).
- [Activación adicional del guardado protegido en Firebase](updates/2.0.8/firebase/Activar-Proteccion-Firebase-2.0.8.md).

El servidor valida cambios de moderadores cuando se configura la credencial privada de Firebase. Esa protección necesita la activación documentada; no basta con instalar el APK. La actualización no requiere migrar ni reiniciar los datos del torneo o de los juegos.

Este repositorio no contiene la clave de firma del APK ni credenciales de Firebase. El proyecto Android completo y su material de firma se mantienen en el respaldo privado del propietario.
